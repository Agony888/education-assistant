# 毕业论文写作系统

## 一、题目优化规则

好题目应满足：

1. 研究对象明确；
2. 核心问题清楚；
3. 范围可控；
4. 方法或场景不过度堆叠；
5. 不夸大效果。

常见问题：

| 问题 | 表现 | 修改方向 |
|---|---|---|
| 题目过大 | AI赋能小学数学教学研究 | 限定环节、对象或场域 |
| 概念模糊 | 应用可能研究 | 改为可行性、现状、策略、路径 |
| 效果夸大 | 提升效果研究 | 若无实验，改为问题、策略、可行性 |
| 对象不明 | 教师教学研究 | 明确小学数学教师、乡村教师等 |

## 二、研究问题生成规则

研究问题一般 2—4 个。

结构：

1. 现状是什么；
2. 问题是什么；
3. 原因是什么；
4. 如何改进。

示例：

```text
1. 小学数学教师当前使用生成式 AI 辅助教学反思的现状如何？
2. 教师在使用过程中面临哪些主要困难？
3. 这些困难形成的原因是什么？
4. 如何优化生成式 AI 辅助小学数学教师教学反思的实践路径？
```

## 三、论文目录规则

常见结构：

```text
第一章 绪论
第二章 概念界定与理论基础
第三章 研究设计
第四章 现状与问题分析
第五章 原因分析与优化策略
结论
```

若是文本分析型：

```text
第一章 绪论
第二章 分析框架构建
第三章 文本样本与编码设计
第四章 文本分析结果
第五章 问题与优化建议
结论
```

若是案例研究型：

```text
第一章 绪论
第二章 理论基础与分析框架
第三章 案例背景与研究设计
第四章 案例过程分析
第五章 实践问题与改进路径
结论
```

## 四、摘要写作

结构：

1. 研究背景；
2. 研究目的；
3. 研究方法；
4. 主要发现；
5. 结论与建议。

避免：
- 摘要只写意义；
- 不写方法；
- 不写具体发现。

## 五、引言写作

结构：

1. 背景；
2. 问题；
3. 已有研究基础；
4. 研究不足；
5. 本研究切入。

## 六、结论写作

结构：

1. 回答研究问题；
2. 概括主要发现；
3. 提出实践建议；
4. 说明研究不足；
5. 展望后续研究。

不要夸大结论，尤其不要把小样本研究写成普遍规律。
