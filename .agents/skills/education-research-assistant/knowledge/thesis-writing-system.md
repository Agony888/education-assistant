# 本科教育毕业论文写作系统

## 一、总原则

毕业论文不是将“背景—现状—问题—策略”填满即可。应先确定：

```text
研究对象与边界
→ 研究目的
→ 研究类型
→ 研究问题
→ 理论或分析维度
→ 数据与方法
→ 论文结构
```

目录服从研究问题和证据，而不是反过来。

## 二、题目优化

一个可实施的题目通常包括：

- 明确研究对象；
- 清楚的核心问题或研究内容；
- 必要的学科、环节或场域限定；
- 与实际方法和数据条件相称的表述。

### 常见风险

| 风险 | 典型表现 | 修改方向 |
|---|---|---|
| 范围过大 | AI赋能小学数学教学研究 | 限定对象、环节、场域或材料 |
| 概念模糊 | 应用可能、赋能机制 | 改为可界定、可观察的概念 |
| 效果夸大 | 提升效果、促进发展 | 无实验时改为现状、过程、问题、质量或可行性 |
| 双重中心 | 同时研究资源与教师全部能力 | 明确主概念与背景概念 |
| 方法写进题目但未实施 | 基于行动研究、实证研究 | 只有真实使用该方法时保留 |
| 结论预设 | ……的问题及对策 | 研究前避免断言一定存在某类问题 |

## 三、核心概念与研究边界

核心概念界定应回答：

1. 本研究中的概念具体指什么；
2. 包括什么，不包括什么；
3. 与相邻概念有何区别；
4. 如何转化为分析维度或研究工具；
5. 该界定依据哪些文献、政策或研究需要。

概念维度若用于问卷、访谈或编码，应在文献综述、核心概念/理论部分形成依据，在研究设计中完成操作化。不能只在问卷部分突然出现。

## 四、研究问题设计

研究问题一般 2—4 个，并符合：

- 能由实际材料回答；
- 不重复论文标题；
- 不把“提出建议”当作唯一研究问题；
- 问题之间存在递进或分工；
- 研究问题的答案能够构成论文核心章节。

### 不同研究类型的问题结构

| 类型 | 常见问题逻辑 |
|---|---|
| 调查研究 | 现状/水平—差异或特点—问题及影响因素—建议 |
| 案例研究 | 情境与过程—参与者行动—关键机制或矛盾—启示 |
| 文本分析 | 内容特征—维度表现—典型问题—优化方向 |
| 实践探索 | 设计依据—实施过程—过程证据—反思完善 |
| 行动研究 | 问题诊断—第一轮行动—调整—多轮变化与反思 |
| 理论/政策分析 | 概念或政策逻辑—核心议题—矛盾与影响—解释或建议 |

## 五、研究类型和目录

具体分流规则读取 `research-type-routing.md`。

### 1. 调查研究型

```text
第一章 绪论
第二章 核心概念、理论基础与分析维度
第三章 研究设计
第四章 调查结果
第五章 问题解释与改进建议
结论
```

### 2. 案例研究型

```text
第一章 绪论
第二章 理论基础与分析框架
第三章 案例情境与研究设计
第四章 案例过程和主题分析
第五章 机制解释与实践启示
结论
```

### 3. 文本分析型

```text
第一章 绪论
第二章 核心概念与分析框架
第三章 样本、编码与研究设计
第四章 文本分析结果
第五章 典型问题与优化建议
结论
```

### 4. 实践探索型

```text
第一章 绪论
第二章 理论依据与设计原则
第三章 实践方案设计
第四章 实施过程与证据分析
第五章 实践反思与路径完善
结论
```

### 5. 行动研究型

```text
第一章 绪论
第二章 理论依据与研究设计
第三章 问题诊断与第一轮行动
第四章 第二轮及后续行动
第五章 多轮变化、反思与启示
结论
```

目录名称应根据题目调整，不能机械复制。

## 六、文献综述

文献综述应完成四项任务：

1. 说明已有研究讨论了哪些核心问题；
2. 呈现主要观点、方法和研究脉络；
3. 评价已有贡献、分歧和局限；
4. 说明本研究建立在什么基础上、解决什么具体问题。

每一段优先采用：

```text
主题判断
→ 综合代表研究
→ 比较与归纳
→ 贡献或不足
→ 与下一段或本研究连接
```

不得将综述写成作者观点清单。

## 七、理论与分析框架

选择理论前先说明理论在论文中承担哪种角色：

- 解释研究对象；
- 生成分析维度；
- 指导工具设计；
- 解释研究结果；
- 建立变量关系。

理论不必多。一个能够贯穿问题、工具和解释的理论，通常优于多个只在第二章出现的理论。

## 八、研究设计

至少建立以下对齐表：

| 研究问题 | 所需数据 | 数据来源 | 方法/工具 | 分析方式 | 结果章节 |
|---|---|---|---|---|---|

无法填写的数据项说明研究问题尚不可操作。

## 九、结果、讨论与建议

### 结果

只报告数据或材料支持的发现，区分描述、比较、关系和解释。

### 讨论

回答：为什么出现这些结果，与已有研究有何一致或差异，理论如何解释，情境条件是什么。

### 建议

每项建议应对应一个已确认问题，并说明实施主体、行动内容和条件。避免“加强重视、完善机制、提升能力”的空泛并列。

## 十、摘要

摘要通常包括：

1. 研究背景与目的；
2. 研究对象和方法；
3. 主要发现；
4. 结论或建议；
5. 关键词。

未完成数据分析前，不编造发现式摘要。

## 十一、引言

推荐逻辑：

```text
现实或政策背景
→ 具体研究问题
→ 已有研究基础
→ 尚未充分解决的问题
→ 本研究目的与价值
```

避免从宏大背景直接跳到具体题目。

## 十二、结论

结论逐项回答研究问题，并包含：

- 主要发现；
- 对理论或实践的有限贡献；
- 研究条件与局限；
- 合理的后续研究方向。

结论强度不得超过样本、方法和证据范围。

## 十三、修改优先级

1. 一级问题：题目、研究问题、方法和结论不一致；
2. 二级问题：概念、理论、维度和工具缺少依据；
3. 三级问题：章节重复、论证跳跃、证据不足；
4. 四级问题：句式、格式和语言润色。

先修结构与证据，再修语言。
