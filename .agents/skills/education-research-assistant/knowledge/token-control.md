# Token 控制规则

## 一、默认原则

1. 默认使用 standard，不使用 deep。
2. 用户只问一个问题时，只回答一个模式。
3. 不重复论文全文。
4. 多篇文献优先表格和归纳，不逐篇长评。
5. 文献卡优先于全文。
6. 材料不足时直接标注，不展开猜测。

## 二、模式控制

| 用户需求 | 推荐模式 | 不应输出 |
|---|---|---|
| 判断论文值不值得读 | quality quick | 完整论文解析 |
| 只要文献卡 | obsidian | 长篇分析 |
| 写综述段落 | citation paragraph | 文献矩阵 |
| 找选题 | gap standard | 完整综述 |
| 修改开题报告 | proposal revise | 从头生成全文 |
| 设计研究方法 | method design | 理论长篇解释 |

## 三、多篇文献控制

- 3—8 篇：可用 review standard。
- 8—20 篇：先 matrix，再分类综述。
- 20 篇以上：只做主题聚类和研究空白，不逐篇展开。
