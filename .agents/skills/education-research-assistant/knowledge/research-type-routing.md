# 教育研究类型分流规则

## 一、使用原则

论文目录、研究问题和研究方法必须先根据研究类型设计，不能默认套用“现状—问题—原因—策略”。

判断时依次回答：

1. 研究主要想描述、解释、评价、改进还是建构？
2. 主要证据来自问卷、访谈、课堂、案例、文本还是实践过程？
3. 是否真实实施了干预或多轮改进？
4. 是否具备相应样本、时间和数据条件？

## 二、类型识别

| 类型 | 核心目的 | 典型证据 | 适用条件 | 常见误用 |
|---|---|---|---|---|
| 调查研究 | 描述现状、差异、关系和影响因素 | 问卷、访谈、统计数据 | 有明确总体、样本和工具 | 小样本却进行复杂推断 |
| 案例研究 | 深入解释具体对象、过程和情境 | 访谈、观察、文本、多源资料 | 有边界清楚的案例 | 只有一次访谈却称案例研究 |
| 文本分析 | 分析教材、教案、作业、反思文本或政策 | 文本样本、编码框架 | 有稳定样本和编码规则 | 只做主观点评 |
| 实践探索 | 设计并呈现一套实践方案或路径 | 实践记录、作品、反馈 | 有真实实施或明确方案 | 未实施却宣称效果 |
| 行动研究 | 在实践中多轮计划、行动、观察、反思 | 多轮课堂与反思证据 | 能真实完成至少两轮改进 | 把一次教学尝试称行动研究 |
| 理论/政策分析 | 解释概念、政策或理论关系 | 文献、政策文本、理论论证 | 有充分文本与严谨框架 | 缺少实证却提出普遍结论 |
| 混合研究 | 结合量化与质性证据解释问题 | 问卷 + 访谈/观察等 | 两类数据均有必要且可完成 | 为显得复杂而堆叠方法 |

## 三、研究问题结构

### 1. 调查研究

```text
现状或水平如何？
不同群体是否存在差异？
主要问题或影响因素是什么？
可据此提出哪些针对性建议？
```

没有足够样本和统计设计时，不提出复杂因果问题。

### 2. 案例研究

```text
案例在具体情境中如何发生？
关键参与者如何行动和理解？
过程呈现哪些特点、矛盾或机制？
案例提供了哪些情境化启示？
```

### 3. 文本分析

```text
分析对象具有什么结构和特征？
各分析维度呈现怎样的分布或表现？
存在哪些典型问题？
文本应如何改进？
```

### 4. 实践探索

```text
实践方案依据什么设计？
实践过程如何实施？
过程证据显示了什么？
方案需要怎样调整和完善？
```

### 5. 行动研究

```text
初始问题是什么？
第一轮行动产生了什么证据？
如何据此调整第二轮行动？
多轮改进形成了哪些变化与反思？
```

## 四、目录路由

### 调查研究型

```text
第一章 绪论
第二章 核心概念、理论基础与分析维度
第三章 研究设计
第四章 调查结果
第五章 问题解释与改进建议
结论
```

### 案例研究型

```text
第一章 绪论
第二章 理论基础与分析框架
第三章 案例选择、情境与研究设计
第四章 案例过程与主题分析
第五章 机制解释、问题与启示
结论
```

### 文本分析型

```text
第一章 绪论
第二章 核心概念与分析框架
第三章 样本、编码与研究设计
第四章 文本分析结果
第五章 典型问题与优化建议
结论
```

### 实践探索型

```text
第一章 绪论
第二章 理论依据与设计原则
第三章 实践方案设计
第四章 实施过程与证据分析
第五章 反思与路径完善
结论
```

### 行动研究型

```text
第一章 绪论
第二章 理论依据与研究设计
第三章 问题诊断与第一轮行动
第四章 第二轮行动及调整
第五章 多轮结果、反思与实践启示
结论
```

### 理论/政策分析型

```text
第一章 绪论
第二章 概念与理论基础
第三章 分析框架与材料范围
第四章 核心议题分析
第五章 理论解释或政策建议
结论
```

## 五、方法与类型一致性

| 类型 | 优先方法 | 必须说明 |
|---|---|---|
| 调查研究 | 问卷、访谈、描述/推断统计 | 样本、工具来源、信效度、分析方式 |
| 案例研究 | 访谈、观察、文本分析、三角互证 | 案例边界、选择理由、资料来源 |
| 文本分析 | 内容分析、编码、比较分析 | 样本规则、维度来源、编码一致性 |
| 实践探索 | 设计研究、观察、作品分析、访谈 | 实施过程、评价证据、局限 |
| 行动研究 | 观察、反思日志、访谈、作品 | 轮次、调整依据、变化证据 |
| 理论/政策分析 | 文献研究、政策文本分析 | 材料范围、分析框架、推理链 |

## 六、风险检查

- 研究类型是否由题目和问题决定，而不是由想使用的方法决定；
- 是否把一次活动写成行动研究；
- 是否把一般性访谈写成案例研究；
- 是否在没有实验时使用“效果”“提升”作为结论；
- 是否因方法过多而超出本科研究能力；
- 目录是否真实反映数据和分析过程。
