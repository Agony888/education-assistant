# Obsidian 教育科研知识库规范

## 一、文件命名

推荐格式：

```text
年份-作者-论文标题.md
```

示例：

```text
2024-王某-生成式人工智能赋能小学数学教学研究.md
```

## 三、rating 建议

| rating | 含义 |
|---|---|
| A | 核心文献，必须精读 |
| B | 重要文献，可重点参考 |
| C | 一般文献，用作背景 |
| D | 弱相关文献 |
| E | 不建议使用 |

## 四、status 建议

| status | 含义 |
|---|---|
| 待读 | 只保存基本信息 |
| 已解析 | 已生成文献卡 |
| 已精读 | 已做深度笔记 |
| 已引用 | 已进入论文写作 |
| 暂不使用 | 暂时不纳入论文 |
