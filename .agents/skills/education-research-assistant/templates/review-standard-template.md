# 多篇文献综述整合

> 本模板用于 `review` 模式。综述必须基于已提供材料，不得用常识补造文献事实。

## 一、材料清点与纳入范围

| 项目 | 数量/说明 |
|---|---|
| 收到材料 |  |
| 完整文献卡 |  |
| 仅摘要或节选 |  |
| 重复材料 |  |
| 信息不足材料 |  |
| 最终纳入 |  |
| 排除及理由 |  |

先声明：本综述结论适用于“本次纳入材料”，不自动代表整个学界。

## 二、文献事实账本

| 编号 | 作者年份 | 主题 | 对象/场景 | 理论 | 方法 | 主要发现 | 局限 | 信息完整度 |
|---|---|---|---|---|---|---|---|---|

作者、年份或结论无法确认时保留空缺并说明，不自行补齐。

## 三、主题聚类

| 主题类别 | 纳入依据 | 代表文献 | 共同问题 | 内部分歧 | 适合写入的位置 |
|---|---|---|---|---|---|

聚类原则优先采用研究问题、对象、场景、理论或方法，不以相似关键词机械归类。

## 四、研究脉络

从以下维度中选择材料真正支持的脉络：

- 时间演进；
- 研究对象扩展；
- 研究内容深化；
- 方法变化；
- 从价值讨论转向实践过程；
- 从宏观政策转向具体学科和场景。

```text

→ ……
→ ……
```

## 十二、可直接使用的综述段落

仅使用账本中能够确认的作者、年份和观点。段落内部采用“总起—综合证据—比较评价—不足过渡”的结构。
