# 文献综述段落与小节生成

## 一、任务范围

输出类型：段落 / 小节 / 修改稿。

主题：

适合放入：研究背景 / 国内外研究现状 / 分类综述 / 研究述评 / 研究不足。

材料状态：作者年份已确认 / 部分确认 / 未确认。

## 二、证据清单

| 文献 | 可使用观点 | 可支持的判断 | 不可扩大之处 |
|---|---|---|---|

材料未提供作者年份时，不自动补充引用信息。

## 三、段落逻辑

```text
中心判断
→ 综合代表研究
→ 比较、归纳或脉络
→ 已有贡献
→ 不足、分歧或过渡
```

只有在段落承担研究述评功能时，才引出本研究。

## 六、证据覆盖检查

| 正文判断 | 支持文献 | 是否有反例 | 表述是否需要降低强度 |
|---|---|---|---|

## 七、语言检查

- [ ] 没有按作者逐篇排队；
- [ ] 没有新增作者、年份和文献；
- [ ] 没有把单篇观点写成学界共识；
- [ ] 没有用空话代替综合评价；
- [ ] 不足判断能够回到材料；
- [ ] 句式长短有变化，避免连续模板句；
- [ ] 保留用户原有语气和有效表达。
