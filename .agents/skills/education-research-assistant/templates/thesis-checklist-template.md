# 毕业论文检查清单

## 一、题目

- [ ] 对象明确
- [ ] 问题具体
- [ ] 范围可控
- [ ] 表述学术规范

## 二、绪论

- [ ] 背景不是空话
- [ ] 研究意义具体
- [ ] 文献综述按主题分类
- [ ] 能自然引出本研究

## 三、研究设计

- [ ] 研究问题可回答
- [ ] 方法可操作
- [ ] 数据来源明确
- [ ] 研究对象可接触

## 四、正文分析

- [ ] 分析有证据支撑
- [ ] 不只是罗列现象
- [ ] 问题与原因区分清楚
- [ ] 策略与问题对应

## 五、结论

- [ ] 回答研究问题
- [ ] 不夸大结论
- [ ] 说明研究不足
- [ ] 提出后续展望
